# ShopAI — использование искусственного интеллекта

## 1. Назначение

AI помогает владельцу магазина подготовить контент каталога и создать первый вариант публичной витрины. Все AI-результаты являются черновиками и проверяются пользователем перед публикацией.

## 2. AI-конструктор сайта

Пользователь заполняет бриф: название магазина, ниша, ассортимент, аудитория, отличие бренда, стиль, тон, палитра и язык. Backend отправляет запрос в Cloudflare Workers AI через OpenAI-совместимый REST endpoint `/ai/v1/chat/completions`.

Модель возвращает JSON с заголовком первого экрана, подзаголовком, блоком о бренде, CTA, преимуществами и SEO-полями. Backend проверяет обязательные значения и отклоняет шаблонные ответы. Frontend показывает результат в предпросмотре, разрешает отредактировать поля и сохраняет `siteConfig` в магазине. Публичная витрина отображает эти данные в контролируемом React-шаблоне. Произвольный HTML/JavaScript от модели не исполняется.

## 3. AI-генерация карточек товара

- Frontend отправляет название, категорию, характеристики и тон на `/api/ai/product-copy`.
- Backend использует Cloudflare Workers AI и просит JSON с `description` и `seoTitle`.
- Если настройки отсутствуют, возвращается явно обозначенный демонстрационный результат для карточки товара.
- Ошибки реального провайдера показываются пользователю, а не маскируются успешной генерацией.

## 4. Настройка Cloudflare Workers AI

1. Откройте Cloudflare Dashboard → **AI → Workers AI → Use REST API**.
2. Создайте Workers AI API Token.
3. Скопируйте Account ID с этой же страницы.
4. Добавьте значения в локальный `.env`:

```env
CLOUDFLARE_ACCOUNT_ID=your_cloudflare_account_id
CLOUDFLARE_API_TOKEN=your_cloudflare_api_token
CLOUDFLARE_AI_MODEL=@cf/google/gemma-4-26b-a4b-it
```

5. Перезапустите backend.

Официальный endpoint:

```text
https://api.cloudflare.com/client/v4/accounts/{ACCOUNT_ID}/ai/v1/chat/completions
```

Запросы выполняются только сервером с заголовком `Authorization: Bearer`. Токен не передаётся во frontend и не должен коммититься в Git.

Модель по умолчанию — `@cf/google/gemma-4-26b-a4b-it`. Доступность, лимиты и стоимость определяются текущим тарифом и настройками Cloudflare.

Не используйте реальные конфиденциальные данные покупателей в тестовых запросах.

## 5. Качество и ограничения

Проверяйте, что AI не выдумывает характеристики, материалы, размеры, гарантии, сертификаты, страну производства, отзывы, скидки и обещания доставки.

AI-текст — черновик, а не подтверждённая характеристика товара. Перед публикацией его проверяет владелец магазина.

Целевой показатель корректности AI-ответов из паспорта проекта нельзя называть достигнутым без тестового набора, правил оценки и сохранённого результата проверки.

## 6. Технические детали генератора сайта

- Cloudflare Workers AI вызывается с сервера.
- Для Gemma 4 в коротких структурированных запросах отключён режим рассуждений через `chat_template_kwargs.enable_thinking=false`.
- Модель должна вернуть JSON с фиксированным набором полей.
- Backend отбрасывает пустые и шаблонные значения, включая буквальную заглушку `string`.
- Ошибки и пустые ответы не маскируются успешным результатом.

## 7. Отчёт об использовании AI в разработке

В отчёте нужно фиксировать фактически применённые инструменты и модели, этапы, объём сгенерированного материала, человеческие изменения, проверки качества и соблюдение лицензий. Не следует приписывать участникам работу, которую они не выполняли. Сгенерированные тексты и графику нельзя выдавать за полностью самостоятельную оригинальную работу без оговорки.
