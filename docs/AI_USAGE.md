# ShopAI — использование искусственного интеллекта

## 1. Назначение

AI помогает владельцу магазина подготовить контент каталога и создать первый вариант публичной витрины. Все AI-результаты являются черновиками и проверяются пользователем перед публикацией.

## 2. AI-конструктор сайта

Пользователь заполняет бриф: название магазина, ниша, ассортимент, аудитория, отличие бренда, стиль, тон, палитра и язык. Backend отправляет запрос в Cloudflare Workers AI через OpenAI-совместимый REST endpoint `/ai/v1/chat/completions`.

Модель возвращает JSON с заголовком первого экрана, описанием, блоком о бренде, CTA, преимуществами и SEO-текстами. Frontend показывает результат в предпросмотре, разрешает отредактировать поля и сохраняет `siteConfig` в магазине. Публичная витрина отображает эти данные в контролируемом React-шаблоне. Произвольный HTML/JavaScript от модели не исполняется.

## 3. AI-генерация карточек товара

- Frontend отправляет название, категорию, характеристики и тон на `/api/ai/product-copy`.
- Backend использует Cloudflare Workers AI и просит JSON с `description` и `seoTitle`.
- Если настройки отсутствуют, возвращается явно обозначенный демонстрационный результат для карточки товара.
- Ошибки реального провайдера показываются пользователю, а не маскируются успешной генерацией.

## 4. Настройка Cloudflare Workers AI

1. Откройте Cloudflare Dashboard → **AI → Workers AI → Use REST API**.
2. Нажмите **Create a Workers AI API Token**, проверьте разрешения и создайте токен.
3. Скопируйте Account ID с этой же страницы.
4. Добавьте значения в локальный `.env`:

```env
CLOUDFLARE_ACCOUNT_ID=your_cloudflare_account_id
CLOUDFLARE_API_TOKEN=your_cloudflare_api_token
CLOUDFLARE_AI_MODEL=@cf/meta/llama-3.1-8b-instruct
```

5. Перезапустите backend.

Официальный endpoint: `https://api.cloudflare.com/client/v4/accounts/{ACCOUNT_ID}/ai/v1/chat/completions`. Запросы выполняются только сервером с заголовком `Authorization: Bearer`.

Workers AI предоставляет бесплатную квоту 10 000 Neurons в сутки. На Free-плане после исчерпания квоты запросы не выполняются; на Workers Paid использование сверх квоты тарифицируется. Некоторые frontier-модели требуют платёжный способ. Для стартовой конфигурации ShopAI выбрана модель `@cf/meta/llama-3.1-8b-instruct`.

Секретный токен не передаётся в браузер и не коммитится в Git. Не используйте реальные конфиденциальные данные покупателей в тестовых запросах.

## 5. Качество и ограничения

Проверяйте, что AI не выдумывает характеристики, материалы, размеры, гарантии, сертификаты, страну производства, отзывы, скидки и обещания доставки. Не указывайте метрики качества как достигнутые до проверки на тестовом наборе.

AI-текст — черновик, а не подтверждённая характеристика товара. Перед публикацией его проверяет владелец магазина.
