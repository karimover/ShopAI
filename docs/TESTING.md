# ShopAI — план тестирования MVP

## Автоматические проверки

    node --check server/index.mjs
    npm test
    npm run build

API-тест проверяет регистрацию владельца, создание товара, AI endpoint в demo mode, публикацию магазина, доступность витрины, оформление заказа, появление заказа в кабинете, списание остатка, отмену и возврат остатка. Отдельно проверяется отказ приватного API без сессии.

## Тесты доступа и данных

- Создать два аккаунта и убедиться, что владелец A не может читать/изменять данные владельца B.
- Попробовать открыть неопубликованный магазин.
- Попробовать заказать больше товара, чем есть в наличии.
- Проверить нулевую/отрицательную цену, дробный и отрицательный остаток.
- Проверить неподдерживаемое и слишком большое изображение.
- Убедиться, что API-ключ AI не появляется в запросах браузера и репозитории.

## Проверка качества AI

Подготовить набор типовых товаров с проверенными характеристиками. Для каждого ответа проверить соответствие источнику, отсутствие выдуманных фактов, грамматику, стиль и SEO-заголовок.

Цель паспорта проекта — не менее 90% корректных AI-ответов. Значение заполняется только после оценки тестового набора.

## Отчётность

Чек-лист не является доказательством прохождения. Фиксировать фактическую дату, окружение, результат, дефект/issue и повторную проверку после исправления.
