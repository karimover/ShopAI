# ShopAI — план и статус тестирования MVP

## Автоматические проверки

Запуск локально:

```bash
node --check server/index.mjs
npm test
npm run build
```

В CI выполняются проверка синтаксиса backend, API-тесты и production build. На последнем проверенном изменении логотипа все три проверки завершились успешно.

Автотесты покрывают:
- сквозной сценарий регистрации, магазина, товара, AI endpoint в demo mode, публикации, витрины, заявки, заказа и возврата остатка;
- отказ приватного API без сессии;
- отклонение шаблонных AI-ответов конструктора сайта.

## Дополнительные тесты доступа и данных

- Создать два аккаунта и проверить, что владелец A не может читать или изменять данные владельца B.
- Открыть неопубликованный магазин.
- Попробовать заказать больше товара, чем есть в наличии.
- Проверить нулевую/отрицательную цену, дробный и отрицательный остаток.
- Проверить неподдерживаемое и слишком большое изображение.
- Убедиться, что API-токен AI отсутствует в запросах браузера и репозитории.

## Проверка качества AI

Подготовить тестовый набор типовых товаров с заранее проверенными характеристиками. Для каждого ответа проверить:
- соответствие исходным данным;
- отсутствие выдуманных фактов;
- грамматику и стиль;
- корректность SEO-заголовка;
- отсутствие шаблонных заглушек.

Цель паспорта проекта — не менее 90% корректных AI-ответов. Значение заполняется только после измерения на тестовом наборе.

Чек-лист сам по себе не доказывает прохождение. Фиксировать фактическую дату, окружение, результат, дефект/issue и повторную проверку после исправления. Не отмечать ручной тест как пройденный только на основании автоматического теста.
