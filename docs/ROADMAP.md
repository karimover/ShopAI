# ShopAI — план дальнейшей разработки

План является предложением для следующих итераций после контрольной точки. Сроки уточняются после оценки команды и согласования с заказчиком.

| Приоритет | Этап | Задачи | Результат |
|---|---|---|---|
| P0 | Валидация требований | Интервью с заказчиком и 5–7 потенциальными пользователями; уточнение обязательных сценариев | Приоритизированные требования |
| P0 | Backend и данные | API, схема БД, магазины, товары, заказы | Серверное хранение и API |
| P0 | Пользователи и роли | Регистрация, вход, восстановление доступа, RBAC | Ролевая модель |
| P0 | Конструктор | Настройки магазина, шаблоны, предпросмотр и публикация | Базовый запуск магазина |
| P0 | AI-помощник | Серверная интеграция LLM, генерация описаний и SEO, обработка ошибок, проверка пользователем | Работающий AI-сценарий |
| P1 | Заказы | Корзина, оформление, статусы, кабинет владельца | Сквозной путь заказа |
| P1 | Оплата | Выбор и подключение двух согласованных платёжных сервисов | Реальная оплата в тестовом окружении |
| P1 | Доставка | Подключение согласованной службы доставки | Расчёт/выбор доставки |
| P1 | Тестирование | Модульные, интеграционные и приёмочные тесты | Отчёт о качестве |
| P2 | Производительность | Нагрузочный профиль, мониторинг, оптимизация | Подтверждённая пропускная способность |
| P2 | Эксплуатация | Документация, обучение, пилот, сбор обратной связи | Подготовка к промышленному запуску |

## Ближайшая итерация

1. Согласовать сценарий MVP и границы ответственности.
2. Утвердить архитектуру и API-контракты.
3. Реализовать backend для пользователей, магазинов, товаров и заказов.
4. Подключить frontend к API вместо локальных демонстрационных данных.
5. Подключить AI-провайдера через серверный адаптер.
6. Подготовить тестовый сценарий от создания магазина до заказа.

## Управление объёмом

В первую очередь реализуется основной пользовательский путь. Второстепенные функции, не влияющие на запуск магазина и базовое управление заказами, переносятся в следующие итерации. Каждая задача должна иметь исполнителя, критерий готовности и оценку трудозатрат.
